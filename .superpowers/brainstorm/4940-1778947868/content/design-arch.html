Design — Section 1: Architecture & Data Flow

What gets built, where it lives, and how data moves end-to-end.

End-to-End Data Flow
1
Photo upload + async Vision analysis
已存在。claude_vision.py → ai_analyses 表 → structured JSON (collar, sleeve, silhouette, closest_patterns…)
2
NEW — GET /analyses/{id}/draft-params ✦
Frontend auto-calls after analysis completes. Backend reads analysis JSON + body_profile measurements (mm) → calls build_draft_params() → returns DraftParamsResponse with design, all options, Armstrong metrics, alternatives, source tags per option.
3
NEW — SmartDraftPanel component ✦
Expandable panel on /analyze page. Renders design selector (top 3 choices), editable option rows (AI-sourced = gold border, default = grey), collapsible Armstrong section. User tweaks, clicks "Draft".
4
POST /patterns/draft (existing)
Panel sends design + measurements + edited options + SA. Returns instance_id + SVG. Pattern saved to pattern_instances table with created_by_ai = true.
5
Redirect → /pattern?redraft={instance_id}
Existing pattern page loads the saved instance. User gets full toolset: redraft, DXF, SVG download, BOM, version history.
