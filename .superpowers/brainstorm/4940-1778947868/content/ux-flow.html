Where does the AI → Pattern Parameters feature live?

After Claude Vision analyses the photo, how does the user go from "analysis result" to "pattern with AI-suggested options"?

A

Smart Draft button on the Analyze page

On the existing /analyze page, after analysis completes, show a prominent "Auto-Draft with AI Params" button. Clicking it immediately generates the best-matching pattern SVG using all AI-detected options (collar style, ease, SA, etc.). The result appears on the same page with a collapsible "params used" summary.

Pros

  • Zero extra navigation — stays on one page
  • Tightest photo → pattern loop
  • Least new UI to build

Cons

  • User can't tweak params before drafting
  • Analyze page already has a lot going on
B

AI Parameters Bridge Panel (inline on Analyze page)

After analysis, an expandable "AI Pattern Parameters" panel appears below the analysis cards. It shows each detected parameter (design choice, collar style, ease level, SA, etc.) as editable chips/dropdowns. User reviews and adjusts, then clicks "Draft with These Settings". The SVG appears below.

Pros

  • User sees and can correct AI decisions
  • Transparent — shows the mapping logic
  • Still one-page experience

Cons

  • More complex UI to build
  • Analyze page gets even longer
C

"Import from Photo" on the Pattern page

The existing /pattern page gets an "Import from Analysis" button. Clicking it opens a selector of recent analyses. Choosing one pre-fills the design selector and all option fields with AI-suggested values. User can then tweak everything before drafting as normal.

Pros

  • Cleanest separation of concerns
  • Full power of the Pattern page options
  • User can combine multiple analyses

Cons

  • Two-page navigation (analyze → pattern)
  • Less "magical" — more manual steps

Pick the UX flow that feels most right for Chailyn's users. You can mix ideas in the terminal too.
