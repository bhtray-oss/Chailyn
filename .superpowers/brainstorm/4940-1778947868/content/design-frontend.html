drafting — "Draft" clicked, spinner shown
error — fetch or draft failed, inline message
Frontend details
• Fetches params on first expand (lazy)
• Switching design re-renders options for that design
• Gold border = AI-sourced, grey = default
• "Reset to Defaults" restores AI-suggested values
• On draft success → router.push('/pattern?redraft=...')
• Bilingual labels from i18n.ts smartDraft.* keys
